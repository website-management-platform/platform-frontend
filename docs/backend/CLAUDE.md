# Universal Website Admin backend — yapay zekâ aracı için giriş

Bu klasör backend'in sözleşmesidir. İşe başlamadan önce sırayla oku:

1. [00-UYGULAMA-REHBERI.md](00-UYGULAMA-REHBERI.md): belge önceliği, kapsam, değişmez kurallar, uygulama sırası, bitti tanımı.
2. [README.md](README.md): dosya haritası ve açık kararlar.
3. [00-conventions.md](00-conventions.md): ortak API kuralları ve hata kodu kataloğu.

Kurallar:

- Belgede olmayan bir uç, alan veya kural uydurma. Belirsiz noktaları `SORULAR.md` dosyasına yaz.
- Aşama aşama ilerle; her aşamayı test çıktısıyla kanıtla.
- Tenant izolasyonu, yetki ve public projeksiyon kurallarında istisna yapma.
